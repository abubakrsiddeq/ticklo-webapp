# TickLO

Ticketing and gate verification for events at Pakistani universities.
*TickLO se ticket lo, befikar raho!*

- `web/` – Next.js 16 web app (public pages, student tickets, organizer dashboard,
  web scanner, admin panel)
- `supabase/` – database migrations, seed data, Edge Functions (shared with the future
  Flutter app)
- `PROGRESS.md` – what is done and how to test it
- `DECISIONS.md` – decisions taken where the requirements were open

(Full setup guide is written at the end of the build – see below once complete.)
